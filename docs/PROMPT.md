## Inference script for kitti odom dataset
Please create an implementation plan for inference scripts for the KITTI Odometry dataset.

Requirements:
1. The inference script must support selecting one of the following models:
   - mapanything
   - pi3x
   - da3_nested
2. Please refer to `scripts/da3_kitti_odom.py` for the overall structure, KITTI Odometry data loading, and inference flow.
3. Please also refer to the notebooks to understand how to load and run inference for each individual model.
4. The plan should clearly describe:
   - script structure
   - argument design
   - model selection and initialization
   - KITTI Odometry dataset loading
   - inference pipeline
   - output format and saving behavior
   - any reusable components that should be shared across models
5. Please identify any model-specific differences that need to be handled separately.

The goal is to design a maintainable inference script framework for KITTI Odometry that can run any of the three models through a unified interface.
